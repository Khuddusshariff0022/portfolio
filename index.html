03 · ai-assisted engineering

How I build with Claude.

AI doesn't replace engineering judgement — it multiplies it. I use Claude Code and the Model Context Protocol (MCP) to automate the toil around shipping software, so more of my time goes to design, reliability and review.

✳ Flagship · in daily team use

Multi-agent bug triage & status reporting

A custom multi-agent system built on Claude Code that takes over two recurring chores on the QBOA team: triaging incoming bugs and producing a verified daily status report. Each agent has one narrow job, and a verification step checks claims against their sources before anything is reported.

  • Specialised agents with narrow, well-defined responsibilities
  • MCP connections so agents read real context instead of guessing
  • A verification pass before output — no unverified claims in the report
  • A human stays in the loop for every decision that matters

my rules for AI in production work

  1. Verify, don't trust. Every agent output is checked against its source.
  2. Narrow agents win. Small, single-purpose agents beat one do-everything prompt.
  3. Protect data. PI/PII rules apply to AI tooling exactly as they do to services.
  4. Humans own decisions. Automation removes toil, not accountability.
